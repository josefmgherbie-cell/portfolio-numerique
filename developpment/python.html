Projet 1 : Calculatrice Interactive en Console

Description du problème : Créer un programme capable d'effectuer les quatre opérations arithmétiques de base (+, -, *, /) entre deux nombres saisis par l'utilisateur, tout en gérant les erreurs courantes comme la division par zéro.

Code source :

def calculatrice():
    while True:
        choix = input("\nOpération (+, -, *, /) ou 'q' pour quitter : ")
        if choix == 'q':
            break
        if choix not in ('+', '-', '*', '/'):
            print("Opération invalide.")
            continue
        try:
            a = float(input("Premier nombre : "))
            b = float(input("Deuxième nombre : "))
            if choix == '+': print(f"Résultat : {a + b}")
            elif choix == '-': print(f"Résultat : {a - b}")
            elif choix == '*': print(f"Résultat : {a * b}")
            elif choix == '/':
                if b == 0:
                    print("Erreur : Division par zéro impossible.")
                else:
                    print(f"Résultat : {a / b}")
        except ValueError:
            print("Erreur : Veuillez entrer des nombres valides.")

calculatrice()

Explication du fonctionnement : Le programme tourne dans une boucle infinie while True jusqu'à ce que l'utilisateur saisisse 'q'. Il vérifie la validité de l'opérateur, convertit les entrées en nombres flottants (float) et utilise un bloc try/except pour intercepter les saisies non numériques.

Difficultés rencontrées et solutions : Au départ, le programme plantait (ValueError) si l'utilisateur tapait une lettre au lieu d'un chiffre. J'ai résolu ce problème en encapsulant les entrées input() dans un bloc try...except ValueError.

Projet 2 : Jeu de Devinettes (Nombre Mystère)

Description du problème : L'ordinateur génère un nombre aléatoire entre 1 et 100. L'utilisateur doit le retrouver en un minimum d'essais grâce aux indices ("Trop grand" ou "Trop petit") fournis après chaque proposition.

Code source :

import random

nombre_secret = random.randint(1, 100)
essais = 0
trouve = False

print("Devinez le nombre entre 1 et 100 !")

while not trouve:
    proposition = int(input("Votre proposition : "))
    essais += 1
    if proposition < nombre_secret:
        print("C'est plus grand !")
    elif proposition > nombre_secret:
        print("C'est plus petit !")
    else:
        print(f"Bravo ! Trouvé en {essais} essais.")
        trouve = True

Explication du fonctionnement : La bibliothèque standard random génère l'entier cible. Une boucle while compare à chaque tour la saisie du joueur avec la valeur secrète et incrémente un compteur essais jusqu'à l'égalité.

Difficultés rencontrées et solutions : La fonction input() renvoie une chaîne de caractères (str), ce qui provoquait une TypeError lors de la comparaison avec un entier. La conversion explicite via int() a corrigé l'erreur.

Projet 3 : Gestionnaire de Notes Étudiant

Description du problème : Permettre à un étudiant de saisir ses notes, d'afficher la liste complète, de calculer sa moyenne générale et d'identifier la note maximale et minimale.

Code source :

notes = []

while True:
    saisie = input("Entrez une note sur 20 (ou 'fin' pour calculer) : ")
    if saisie.lower() == 'fin':
        break
    note = float(saisie)
    if 0 <= note <= 20:
        notes.append(note)
    else:
        print("La note doit être comprise entre 0 et 20.")

if len(notes) > 0:
    moyenne = sum(notes) / len(notes)
    print(f"\nNotes saisies : {notes}")
    print(f"Moyenne : {moyenne:.2f}/20 | Max : {max(notes)} | Min : {min(notes)}")
else:
    print("Aucune note enregistrée.")

Explication du fonctionnement : Les notes valides sont ajoutées dynamiquement dans une liste Python via append(). Une fois la saisie terminée, les fonctions natives sum(), len(), max() et min() permettent d'extraire instantanément les statistiques.

Difficultés rencontrées et solutions : Si l'utilisateur tapait 'fin' directement sans saisir de note, le calcul sum(notes)/len(notes) provoquait une division par zéro (ZeroDivisionError). L'ajout de la condition if len(notes) > 0: a sécurisé le programme.
