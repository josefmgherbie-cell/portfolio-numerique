1. Recherche du Maximum dans un Tableau

Idée générale : On suppose initialement que le premier élément du tableau est le plus grand. On parcourt ensuite le reste du tableau élément par élément : dès qu'on trouve une valeur strictement supérieure au maximum actuel, on met à jour ce maximum.

Exemple pas à pas avec T = [12, 45, 7, 89, 23] :

  • Initialisation : max = 12 (index 0).
  • Index 1 (45) : 45 > 12 → max devient 45.
  • Index 2 (7) : 7 < 45 → max reste 45.
  • Index 3 (89) : 89 > 45 → max devient 89.
  • Index 4 (23) : 23 < 89 → Fin du parcours, résultat : 89.
Pseudo-code : 
Algorithme RechercheMax
Variables : T : Tableau d'entiers, n, i, max : Entiers
Début
    max ← T[0]
    Pour i de 1 à n - 1 Faire
        Si T[i] > max Alors
            max ← T[i]
        FinSi
    FinPour
    Retourner max
Fin
Traduction en Python : 
def recherche_max(T):
    maximum = T[0]
    for i in range(1, len(T)):
        if T[i] > maximum:
            maximum = T[i]
    return maximum

2. Recherche Séquentielle (Linéaire)

Idée générale : Parcourir un tableau du début à la fin pour vérifier si une valeur cible x s'y trouve. Dès qu'elle est trouvée, on retourne sa position (son indice). Si on atteint la fin sans succès, on retourne -1.

Exemple pas à pas : Chercher x = 30 dans T = [10, 20, 30, 40] :

  • i = 0 : T[0] = 10 ≠ 30 (on continue).
  • i = 1 : T[1] = 20 ≠ 30 (on continue).
  • i = 2 : T[2] = 30 == 30 (trouvé ! On arrête et on renvoie l'indice 2).
Pseudo-code : 
Algorithme RechercheSequentielle
Variables : T : Tableau, n, x, i : Entiers
Début
    Pour i de 0 à n - 1 Faire
        Si T[i] = x Alors
            Retourner i
        FinSi
    FinPour
    Retourner -1
Fin
Traduction en Langage C : 
int recherche(int T[], int n, int x) {
    for (int i = 0; i < n; i++) {
        if (T[i] == x) {
            return i;
        }
    }
    return -1;
}

3. Tri à Bulles (Bubble Sort)

Idée générale : Comparer répétitivement les éléments adjacents d'un tableau et les échanger s'ils sont dans le mauvais ordre. À chaque passage complet, le plus grand élément non trié "remonte" à sa place définitive à la fin du tableau, comme une bulle d'air.

Exemple pas à pas avec [5, 1, 4, 2] (1er passage) :

  • Compare (5, 1) → échange → [1, 5, 4, 2]
  • Compare (5, 4) → échange → [1, 4, 5, 2]
  • Compare (5, 2) → échange → [1, 4, 2, 5] (5 est bien placé).
Pseudo-code : 
Algorithme TriBulles
Variables : T : Tableau, n, i, j, temp : Entiers
Début
    Pour i de 0 à n - 2 Faire
        Pour j de 0 à n - i - 2 Faire
            Si T[j] > T[j + 1] Alors
                temp ← T[j]
                T[j] ← T[j + 1]
                T[j + 1] ← temp
            FinSi
        FinPour
    FinPour
Fin
Traduction en Python : 
def tri_bulles(T):
    n = len(T)
    for i in range(n - 1):
        for j in range(n - i - 1):
            if T[j] > T[j + 1]:
                T[j], T[j + 1] = T[j + 1], T[j]
