Programme 1 : Variables, Conditions et Boucles (Factorielle)

Notions illustrées : Déclaration de types stricts (int, unsigned long long), entrées/sorties formatées (scanf, printf), structure conditionnelle if/else et boucle for. 

#include <stdio.h>

int main() {
    int n, i;
    unsigned long long fact = 1;

    printf("Entrez un entier positif : ");
    scanf("%d", &n);

    if (n < 0) {
        printf("Erreur : la factorielle d'un nombre negatif n'existe pas.\n");
    } else {
        for (i = 1; i <= n; ++i) {
            fact *= i;
        }
        printf("Factorielle de %d = %llu\n", n, fact);
    }
    return 0;
}

Programme 2 : Tableaux et Fonctions (Moyenne d'un tableau)

Notions illustrées : Passage d'un tableau en paramètre d'une fonction, parcours par indexation et séparation de la logique métier de la fonction principale main(). 

#include <stdio.h>

float calculerMoyenne(float tab[], int taille) {
    float somme = 0.0;
    for (int i = 0; i < taille; i++) {
        somme += tab[i];
    }
    return somme / taille;
}

int main() {
    float notes[4] = {14.5, 12.0, 16.5, 11.0};
    float moy = calculerMoyenne(notes, 4);
    
    printf("La moyenne des 4 notes est : %.2f\n", moy);
    return 0;
}

Programme 3 : Pointeurs et Passage par Adresse (Échange de valeurs)

Notions illustrées : Manipulation directe des adresses mémoire avec l'opérateur & et déréférencement avec * pour modifier des variables en dehors de la portée locale de la fonction. 

#include <stdio.h>

void echanger(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 10, y = 25;
    printf("Avant echange : x = %d, y = %d\n", x, y);
    
    echanger(&x, &y); // Envoi des adresses memoire
    
    printf("Apres echange : x = %d, y = %d\n", x, y);
    return 0;
}

Tableau Comparatif : Python vs Langage C

Critère Python Langage C
Syntaxe Épurée et lisible, proche de l'anglais. Les blocs de code sont délimités par l'indentation (espaces) sans point-virgule. Plus stricte et verbeuse. Nécessite des accolades { } pour les blocs et un point-virgule ; à la fin de chaque instruction.
Typage Dynamique et implicite : on n'a pas besoin de déclarer le type d'une variable, il peut même changer en cours d'exécution. Statique et explicite : chaque variable doit avoir un type fixe déclaré à l'avance (int, float, char).
Gestion de la mémoire Automatique grâce au Garbage Collector (ramasse-miettes) qui libère la mémoire inutilisée tout seul. Manuelle : le programmeur gère les adresses (pointeurs) et doit allouer/libérer la mémoire lui-même (malloc / free).
Rapidité Plus lent, car le code est interprété ligne par ligne au moment de l'exécution. Extrêmement rapide : le code est compilé directement en langage machine compréhensible par le processeur.
Usages principaux Science des données, Intelligence Artificielle, développement web back-end, automatisation et scripts rapides. Systèmes d'exploitation (noyau Linux), systèmes embarqués, microcontrôleurs, pilotes matériels et moteurs de jeux.
